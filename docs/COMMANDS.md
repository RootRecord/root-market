# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/market` | Open the market browse GUI | `` | `/market / /market <item/player>` |
| `/shops` | Browse one player's sell listings | `` | `/shops <player>` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootmarket.use` | Use /market /items /shops | `true` |
